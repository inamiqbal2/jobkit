# Example State University - M.S. thesis research, Aug 2020 - May 2022, Fort Collins CO
Status: CONFIRMED-BY-USER 2026-10-08 (fabricated example)

## What the work actually was
Hosting-capacity estimation for distribution feeders with high rooftop-solar penetration: Monte Carlo placement of
PV on OpenDSS feeder models, voltage-violation statistics, a regression model that predicts hosting capacity from
feeder features. One conference paper (fabricated: "Example Conf. on Power Systems 2022").

## Technical specifics
OpenDSS (operated), Python (pandas, scikit-learn for the regression only - no deep learning), MATLAB for plots.

## Real numbers (provenance)
- 6 feeder models, 10,000 Monte Carlo placements each (thesis ch. 4) - confirmed.
