# system/examples/taylor_example - a FABRICATED workspace for smoke-testing jobkit in a non-materials field

"Taylor Example" does not exist. Every fact below was invented on 2026-10-08 to show what a workspace looks
like after the onboarding skill has run for a power-systems electrical engineer (M.S., four years at a utility and a
grid-software startup, U.S. citizen, Denver, relocation yes; lanes: power systems engineering, grid analytics, test
engineering). Nothing here is a template to copy facts from; it is a template to copy the SHAPE from.

Run the engine against it:
```
export JOBKIT_WORKSPACE="$PWD/system/examples/"taylor_example
system/.venv/bin/python system/engine/tools/userconfig.py
system/.venv/bin/python system/engine/tools/registries.py assemble
system/.venv/bin/python system/engine/tools/approved_claims.py
```
`tracking/` is empty on purpose (corpus, state.db, caches are generated by a run and git-ignored).
